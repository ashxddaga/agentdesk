📖 MULTI-AGENT ORCHESTRATION & /teamwork GUIDE FRAMEWORK

⚡ The 4-Tier Multi-Agent Stack

Orchestrating agents effectively requires separating concerns across four durable tiers:

Tier 1: AgentDesk Cockpit

Your mobile & desktop command center on port 9876. Live streaming terminal peek, tactile macro keypad, priority attention sorting (done/blocked on top), and real-time swarm radar.

Tier 2: AgentR Switchboard & Blackboard

Shared project task ledger (BOARD.md / .agentr/tasks.json), cross-agent session search, live context snapshotting, and task dispatcher.

Tier 3: Herdr Terminal Multiplexer

Manages named workspaces (~General, ~CAD, ~AgentR) and split terminal panes (w7:p1, w7:p2). Provides socket RPC to safely read buffers and send input without terminating agents.

Tier 4: Agent Fleet & Native Frameworks

The actual intelligence engines: Antigravity (agy) with native /teamwork and subagents; OpenCode (opencode) with free DeepSeek Flash; Freebuff and Grok.

🤖 Leveraging Antigravity Native /teamwork

Antigravity contains a built-in multi-agent subagent system invoked via /teamwork or teamwork_preview:

4 Team Shapes available in /teamwork:
  • Small, Focused Team (Best for Bug Fixes): 1 implementer + repeated adversarial reviews. Prompt directive: "This is a single self-contained fix; keep it small and focused."
  • Full Team: Multi-phase architect, researchers, implementers, and QA for major features and builds.
  • Large Swarm Team: 100+ concurrent agents for complex theorem proving and mathematical problem solving. Prompt directive: "Use a very large team of agents."
  • Document Review Team: In-depth architectural spec and whitepaper audit.
The Teamwork Contract: Specify What, Not How

Always specify clear Requirements (R1, R2) and objective Acceptance Criteria (e.g. cargo test passes). Avoid over-specifying internal implementation details so the agent team can explore the best solution.

🛰️ Cross-Agent Dispatch into Herdr Panes

Instead of running multiple agents inside one process or hijacking your active terminal, use AgentR to dispatch tasks into side-by-side Herdr panes:

# Split current workspace & run OpenCode in parallel:
agentr task dispatch task-16 --pane

# Dispatch into a brand new Herdr workspace:
agentr task dispatch task-15 --workspace "CAD-Fleet"

# Dispatch with automatic /teamwork formatting:
agentr task dispatch task-15 --teamwork small --pane

The dispatched agent launches in its own dedicated terminal pane, visible on your desktop and in AgentDesk. The calling agent continues running uninterrupted!

🔄 The Autonomous Bug-Fixing Loop

To keep the CAD agent and AgentR working without human intervention, follow this high-level loop:

  1. Find Bugs: Architect agent identifies bugs in the target repository.
  2. Register on Board: Run agentr task add "<title>" --agent opencode --desc "<details>".
  3. Dispatch to Panes: Run agentr task dispatch <id> --pane.
  4. Report Platform Friction: If an agent hits an AgentR/Herdr issue, run agentr feedback "<friction>".
  5. AgentR Self-Heals: The ~AgentR workspace agent reads feedback, fixes the framework, runs tests, and deploys live!
